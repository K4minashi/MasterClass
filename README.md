# 🚀 Добро пожаловать на мастер-класс по Git!

Привет! Сегодня мы с тобой почувствуем себя настоящими разработчиками. Мы будем работать над общим проектом, не мешая друг другу, и в конце урока твоё имя навсегда останется в истории этого репозитория.

## 📋 Твой план действий:

1. **Зарегистрируйся и создай Токен:**
   - Нажми на свой аватар справа сверху → **Настройки** → **Настройки для разработчика** → **Класические токены**.
   - Создай новый токен: имя `lesson`, срок `неделя`, права: поставьте галочки везде.
   - **Скопируй токен** и сохрани его в Блокнот! Он больше не покажется.

2. **Отметься в задаче (Обязательно!):**
   - Перейди во вкладку **Задачи** (Issues) в этом репозитории.
   - Открой задачу с названием **«Добавление в репозиторий»**.
   - Напиши в комментариях любое сообщение (например, свой никнейм или «Привет, я готов!»).
   - *Учитель увидит твой комментарий, найдет твой профиль и добавит тебя в участники проекта.*

3. **Открой Шпаргалку** (она на экране находится в это репозитории под названием Шпаргалка.md) и следуй шагам которые описаны в ней.

## 🎯 Твоя задача:
Создать свою личную ветку, добавить туда файл `contributors/твое_имя.md` с парой строк о себе и предложить свои изменения через **Merge Request**.

Удачи! Если что-то идет не так — подними руку, мы всё решим. 🛠️
