🚀 ШПАРГАЛКА ПО GIT: КАК РАБОТАТЬ В КОМАНДЕ И НЕ СОЙТИ С УМА

ШАГ 1: Создаем задачу (Issue) на сайте
--------------------------------------
В реальном IT код не пишут просто так — сначала создают задачу!
1. D браузере, зайди в свой репозиторий.
2. Перейди во вкладку **Задачи** (Issues) сверху.
3. Нажми **Новая задача** (New Issue).
4. В заголовке напиши: "Добавить файл [Твое Имя]".
5. Укажи ответственного за задачу справа, выбери свой аккаунт.
6. Нажми **Создать задачу**. Теперь у тебя есть официальный тикет на твою работу!

ШАГ 2: Скачиваем проект с секретным ключом (Токеном)
----------------------------------------------------
1. Создай папку на Рабочем столе (например, "GitLesson").
2. Зайди в неё, нажми ПРАВОЙ кнопкой мыши → "Git Bash Here".
3. Как получить ссылку?
   - Зайди на страницу репозитория в браузере.
   - Найди кнопку «Код» в открывшейся вкладке нажми «HTTPS» и скопируй ссылку.
4. Вставь свой ТОКЕН в начало ссылки (сразу после https://) и выполни команду:

   `git clone https://<ТВОЙ_ТОКЕН>@gitverse.ru/Kaminashi/MasterClass.git`

5. Зайди в скачанную папку с помощью команды:
   `cd НАЗВАНИЕ_РЕПО`

💡 Магия: Токен в ссылке запомнится. При отправке кода Git НЕ будет спрашивать пароль!


ШАГ 3: Представляем себя Git'у (Обязательно!)
----------------------------------------------
Git должен знать, чье имя вшить в "точку сохранения". Замени данные на свои:

   `git config --global user.name "Иван Иванов"`
   
   `git config --global user.email "ivan@school.local"`

*(Почта может быть любой, даже выдуманной, главное — формат email).*


ШАГ 4: Создаем свою "параллельную вселенную" (Ветку)
----------------------------------------------------
Чтобы не сломать главный проект, мы создаем свою изолированную ветку.
Замени "imya" на свое имя (без пробелов):

   `git checkout -b feature/imya`


ШАГ 5: Выполняем задачу (Редактируем через nano)
-------------------------------------------------
В терминале (Git Bash) введи команду для открытия редактора nano:
   `mkdir contributors`
   `nano contributors/imya.md`

1. Откроется редактор. Напиши что-то про себя например: 
   "Привет, я Егор! Мое хобби: программирование."
2. Сохранение и выход (запомни эти кнопки!):
   - Нажми Ctrl+O (сохранить), затем нажми Enter (подтвердить имя файла).
   - Нажми Ctrl+X (выйти из редактора).


ШАГ 6: Делаем "Точку сохранения" (Коммит)
-----------------------------------------
Возвращаемся в терминал:

   `git status`       (Проверь: твой файл должен гореть красным цветом)
   `git add .`           (Говорим Git'у: "Забирай все изменения")
   `git commit -m "Добавил файл Егора"`  (Делаем снимок с подписью)


ШАГ 7: Отправляем ветку в облако (Push)
---------------------------------------
   `git push -u origin feature/imya`

⚠️ ВНИМАНИЕ: Если Git спросит Username и Password — это ошибка! 
Ты должен был вставить токен в Шаге 1. Если спрашивает — проверь, 
не опечатался ли ты в ссылке при клонировании.


ШАГ 8: Объединяем работу с главной (Merge Request)
--------------------------------------------------
1. Обнови страницу репозитория в браузере (F5).
2. Ты увидишь желтую плашку: "У вас есть новая ветка. Сравнить и создать Merge Request".
3. Нажми на неё. Убедись, что заголовок понятный (например, "Добавлен Иван").
4. Нажми кнопку "Создать Merge Request" (или "Отправить на проверку").
5. Жди, пока учитель нажмет "Merge" (Слить)!

ШАГ 9 (БОНУС): Слияние веток через терминал (Для самых быстрых!)
----------------------------------------------------------------
Если ты хочешь понять, как кнопка "Merge" работает изнутри, или хочешь слить ветку сам, используй эти команды в терминале:

   `git checkout main`         (1. Переключаемся на главную ветку)
   `git merge feature/imya`     (2. Сливаем нашу ветку в главную)
   `git push origin main`       (3. Отправляем обновленную главную ветку на сервер)

💡 ВАЖНО: 
- Если Git напишет "Already up to date" (Уже обновлено) — не пугайся! Это значит, что учитель уже слил твою ветку через сайт в Шаге 8, и всё работает идеально.
- Если Git напишет "CONFLICT" (Конфликт) — значит, кто-то другой изменил те же строки. В реальном IT это решается вручную, но на нашем уроке просто позови учителя, мы разрулим это за 10 секунд!

======================================================================
🆘 ЧТО ДЕЛАТЬ, ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК?
======================================================================
- Ошибка "fatal: not a git repository": Ты забыл зайти в папку! Напиши: cd НАЗВАНИЕ_РЕПО
- Ошибка "nothing to commit": Ты не сохранил файл в nano (Ctrl+O, Enter) или создал его не в той папке.
- Не можешь выйти из nano: Нажми Ctrl+X. Если он спросит "Save modified buffer?", нажми Y (Yes) и Enter.
